# vnstock quickstart cho nhà nghiên cứu dữ liệu

`vnstock` là thư viện Python để truy cập dữ liệu thị trường chứng khoán Việt Nam — giá lịch sử, realtime quote, thông tin doanh nghiệp và nhiều hơn nữa — không cần tài khoản môi giới hay key trả phí.

VNInvest sử dụng một fork nội bộ của `vnstock` (`vietdung-edusuccess/vnstock`) với một số bản vá chưa merge vào upstream, nhưng API public không thay đổi.

## Cài đặt

```bash
pip install vnstock
```

Hoặc cài fork nội bộ (nếu bạn đang chạy cùng pipeline với VNInvest):

```bash
pip install git+https://github.com/vietdung-edusuccess/vnstock.git@main
```

## Lấy dữ liệu giá lịch sử

```python
from vnstock import *

# Giá ngày VNM từ đầu năm 2024
price = quote.history(symbol='VNM', start='2024-01-01', end='2024-06-30')
print(price.head())
#    time    open    high     low   close  volume
# 0  2024-01-02  79.1  80.4  78.9   79.8  1234567
```

## Lấy dữ liệu intraday

```python
# Dữ liệu khớp lệnh trong phiên hôm nay
intraday = quote.intraday(symbol='VCB', page_size=100)
```

## Thông tin doanh nghiệp

```python
from vnstock import company

profile = company.overview(symbol='HPG')
# Trả về: tên, ngành, vốn hóa, EPS, P/E...
```

## Danh sách mã chứng khoán

```python
from vnstock import listing

# Tất cả mã HOSE/HNX/UPCOM
all_symbols = listing.all_symbols()
print(f"Tổng cộng: {len(all_symbols)} mã")
```

## Lưu ý về dữ liệu

`vnstock` kéo dữ liệu từ các nguồn công khai. Với dữ liệu intraday, rate limit của provider có thể kích hoạt khi query tần suất cao. VNInvest giải quyết điều này bằng lớp prefetch Celery + Redis: dữ liệu được cache trước theo chu kỳ 5 giây và phục vụ từ cache thay vì gọi thẳng vnstock mỗi request.
