## 1. Migration Objectives

1.  Tạo bản ghi `TenantMember` cho **tất cả** tenant hiện có từ `CoreTenant.owner_user`.
2.  Gán role `OWNER` cho `owner_user` trên tenant của họ.
3.  Đảm bảo `TenantMember.status = ACTIVE` cho các owner hiện tại.
4.  Không mất dữ liệu, không downtime (chạy online), có rollback plan.
5.  Verification queries chứng minh data integrity post-migration.

    id = models.UUIDField(primary_key=True, default=uuid.uuid4)
    tenant = models.ForeignKey('CoreTenant', on_delete=models.CASCADE, related_name='members')
    user = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE, related_name='tenant_memberships')
    role = models.CharField(max_length=20, choices=RoleChoices.choices)  # OWNER, ADMIN, MEMBER, VIEWER
    status = models.CharField(max_length=20, choices=MemberStatusChoices.choices, default='ACTIVE')  # ACTIVE, INVITED, SUSPENDED, REVOKED
    invited_by = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.SET_NULL, null=True, related_name='invited_members')
    invited_at = models.DateTimeField(auto_now_add=True)
    joined_at = models.DateTimeField(null=True, blank=True)  # Null cho INVITED, set khi accept

    class Meta:
        unique_together = ('tenant', 'user')  # 1 user = 1 membership per tenant
        indexes = [
            models.Index(fields=['tenant', 'status']),
            models.Index(fields=['user', 'status']),
        ]

# CoreTenant changes:
# - owner_user: DEPRECATED (giữ column, thêm comment, không dùng trong logic mới)
# - status: giữ nguyên (ACTIVE, SUSPENDED, DEPROVISIONED)

### Bước 2: Data Migration Script (RunPython) — **QUAN TRỌNG**

**File:** `core/migrations/00XX_populate_tenant_member_from_owner.py`

```python
# core/migrations/00XX_populate_tenant_member_from_owner.py
from django.db import migrations
from django.db import transaction

def populate_tenant_members(apps, schema_editor):
    """
    Tạo TenantMember cho mỗi CoreTenant từ owner_user.
    Chạy trong transaction để atomic.
    """
    CoreTenant = apps.get_model('core', 'CoreTenant')
    TenantMember = apps.get_model('core', 'TenantMember')
    User = apps.get_model('auth', 'User')  # hoặc settings.AUTH_USER_MODEL

    # Lấy tất cả tenant có owner_user
    tenants = CoreTenant.objects.select_related('owner_user').filter(owner_user__isnull=False)

    created_count = 0
    skipped_count = 0
    errors = []

    for tenant in tenants:
        owner = tenant.owner_user
        if not owner:
            errors.append(f"Tenant {tenant.id} ({tenant.name}) has no owner_user")
            continue

        # Kiểm tra đã có membership chưa (idempotent)
        existing = TenantMember.objects.filter(tenant=tenant, user=owner).first()
        if existing:
            skipped_count += 1
            # Ensure status=ACTIVE, role=OWNER
            if existing.role != 'OWNER' or existing.status != 'ACTIVE':
                existing.role = 'OWNER'
                existing.status = 'ACTIVE'
                existing.joined_at = existing.invited_at  # hoặc timezone.now()
                existing.save(update_fields=['role', 'status', 'joined_at'])
            continue

        try:
            with transaction.atomic():
                TenantMember.objects.create(
                    tenant=tenant,
                    user=owner,
                    role='OWNER',
                    status='ACTIVE',
                    invited_by=owner,  # Self-invited
                    joined_at=tenant.created_at,  # hoặc timezone.now()
                )
                created_count += 1
        except Exception as e:
            errors.append(f"Failed to create TenantMember for tenant {tenant.id}: {e}")

    # Log summary
    print(f"[MIGRATION] TenantMember population: created={created_count}, skipped={skipped_count}, errors={len(errors)}")
    if errors:
        for err in errors:
            print(f"[MIGRATION ERROR] {err}")
        # Không raise exception để migration không fail hoàn toàn, nhưng log rõ ràng
        # Hoặc raise nếu muốn strict: raise Exception(f"Migration errors: {errors}")

def reverse_populate_tenant_members(apps, schema_editor):
    """
    Rollback: Xóa TenantMember được tạo bởi migration này.
    Chỉ xóa những record có role=OWNER và invited_by=user (self-invited).
    """
    TenantMember = apps.get_model('core', 'TenantMember')
    deleted, _ = TenantMember.objects.filter(role='OWNER', invited_by=models.F('user')).delete()
    print(f"[MIGRATION ROLLBACK] Deleted {deleted} TenantMember records")

class Migration(migrations.Migration):

    dependencies = [
        ('core', '00XX_create_tenant_member'),  # Migration tạo model
    ]

    operations = [
        migrations.RunPython(populate_tenant_members, reverse_populate_tenant_members),
    ]
```

## 4. Verification Queries (Post-Migration)

Chạy sau migration trên **staging & production** để xác minh:

```sql
-- 1. Tổng số tenant vs tổng số TenantMember (OWNER)
SELECT
    (SELECT count(*) FROM core_coretenant WHERE owner_user_id IS NOT NULL) AS total_tenants_with_owner,
    (SELECT count(*) FROM core_tenantmember WHERE role = 'OWNER' AND status = 'ACTIVE') AS total_owner_memberships;

-- Kết quả 2 cột phải BẰNG NHAU.

-- 2. Tenant có owner_user nhưng KHÔNG có TenantMember OWNER
SELECT ct.id, ct.name, ct.owner_user_id
FROM core_coretenant ct
LEFT JOIN core_tenantmember tm ON tm.tenant_id = ct.id AND tm.user_id = ct.owner_user_id AND tm.role = 'OWNER' AND tm.status = 'ACTIVE'
WHERE ct.owner_user_id IS NOT NULL AND tm.id IS NULL;

-- Kết quả phải RỖNG (0 rows).

-- 3. TenantMember trùng lặp (violate unique_together)
SELECT tenant_id, user_id, count(*)
FROM core_tenantmember
GROUP BY tenant_id, user_id
HAVING count(*) > 1;

-- Kết quả phải RỖNG.

-- 4. Tenant status distribution
SELECT status, count(*) FROM core_coretenant GROUP BY status;

-- 5. TenantMember status distribution
SELECT status, count(*) FROM core_tenantmember GROUP BY status;

-- 6. Sample check: 5 tenant ngẫu nhiên
SELECT ct.id, ct.name, ct.owner_user_id, tm.role, tm.status, tm.joined_at
FROM core_coretenant ct
JOIN core_tenantmember tm ON tm.tenant_id = ct.id AND tm.user_id = ct.owner_user_id
WHERE tm.role = 'OWNER'
ORDER BY random()
LIMIT 5;
```

**Script verification tự động:** `core/management/commands/verify_tenant_migration.py`

```python
# core/management/commands/verify_tenant_migration.py
from django.core.management.base import BaseCommand
from django.db import connection

class Command(BaseCommand):
    help = 'Verify TenantMember migration integrity'

    def handle(self, *args, **options):
        with connection.cursor() as cursor:
            # Query 1
            cursor.execute("""
                SELECT
                    (SELECT count(*) FROM core_coretenant WHERE owner_user_id IS NOT NULL) AS total_tenants,
                    (SELECT count(*) FROM core_tenantmember WHERE role = 'OWNER' AND status = 'ACTIVE') AS total_memberships
            """)
            total_tenants, total_memberships = cursor.fetchone()
            assert total_tenants == total_memberships, f"MISMATCH: tenants={total_tenants}, memberships={total_memberships}"
            self.stdout.write(self.style.SUCCESS(f"✓ Total match: {total_tenants}"))

            # Query 2
            cursor.execute("""
                SELECT ct.id, ct.name FROM core_coretenant ct
                LEFT JOIN core_tenantmember tm ON tm.tenant_id = ct.id AND tm.user_id = ct.owner_user_id AND tm.role = 'OWNER' AND tm.status = 'ACTIVE'
                WHERE ct.owner_user_id IS NOT NULL AND tm.id IS NULL
            """)
            missing = cursor.fetchall()
            assert len(missing) == 0, f"Missing memberships: {missing}"
            self.stdout.write(self.style.SUCCESS("✓ No missing memberships"))

            # Query 3
            cursor.execute("""
                SELECT tenant_id, user_id, count(*) FROM core_tenantmember
                GROUP BY tenant_id, user_id HAVING count(*) > 1
            """)
            dupes = cursor.fetchall()
            assert len(dupes) == 0, f"Duplicates: {dupes}"
            self.stdout.write(self.style.SUCCESS("✓ No duplicates"))

        self.stdout.write(self.style.SUCCESS("🎉 ALL VERIFICATIONS PASSED"))
```

Chạy: `python manage.py verify_tenant_migration`

## 5. Rollback Plan

### Scenario 1: Migration chưa chạy (Pre-deploy)
- Không cần rollback. Chỉ không deploy middleware mới.

### Scenario 2: Migration chạy nhưng verification FAIL (Staging)
1.  `python manage.py migrate core 00XX_create_tenant_member` (rollback data migration + model creation).
2.  Fix script migration.
3.  Chạy lại.

### Scenario 3: Migration chạy xong, deploy middleware, nhưng production có lỗi (Critical)
**Feature Flag:** `TENANT_RESOLUTION_MIDDLEWARE_ENABLED` (default `False`).
1.  Tắt feature flag → Middleware bỏ qua, fallback về logic cũ (nếu còn) hoặc trả 503.
2.  Rollback data: `python manage.py migrate core 00XX_create_tenant_member` (gọi `reverse_populate_tenant_members`).
3.  Rollback code: Revert commit middleware.
4.  Deploy hotfix.

> **Lưu ý:** `CoreTenant.owner_user` **KHÔNG XÓA** column. Chỉ deprecate. Rollback data migration chỉ xóa `TenantMember` records.

## 7. Post-Deployment Validation (Smoke Tests)

1.  Login user owner → Access `/tenant-admin/home` → 200 OK.
2.  Login user member (được invite sau migration) → Access tenant → 200 OK.
3.  Login user không phải member → Access tenant → 403 Forbidden.
4.  API call với `X-Tenant-ID` valid → 200.
5.  API call không có `X-Tenant-ID` → 400 `TENANT_HEADER_MISSING`.
6.  API call với `X-Tenant-ID` tenant khác → 403.
7.  Tenant status `SUSPENDED` → 403 `TENANT_SUSPENDED`.
