Tai lieu nay chuan hoa cach van hanh moi tuan cho team (BE/FE/QA/DevOps) de bam sat roadmap.

## 1. Lich van hanh co dinh

- Thu Hai 09:00-10:30: Sprint Planning + cam ket scope tuan.
- Thu Hai 17:00: Risk check lan 1.
- Thu Tu 17:00: Mid-week review (scope, blocker, estimate).
- Thu Sau 16:00-17:00: Demo + Retro + cap nhat KPI.

## 5. Mid-week Review (Thu Tu)

Checklist:
- Scope drift > 20%? Neu co, cat scope P2 truoc.
- P0 nao dang Blocked > 1 ngay?
- Can swap owner/task de giu tien do khong?
- KPI co nguy co truot khong?

Quyet dinh sau buoi hop:
- Keep scope / Reduce scope / Re-plan.

## 6. Definition of Done gate

Task chi duoc Done neu dat tat ca:
- Code + test pass local.
- Contract API cap nhat neu co thay doi response.
- Co migration/rollback note neu lien quan DB.
- Co log/metric co ban neu lien quan background task.
- PR duoc review >= 1 nguoi.

## 7. Demo va Retro (Thu Sau)

Demo:
- Hien thi ket qua theo user flow that.
- So sanh voi KPI dau tuan.

Retro (4 cau bat buoc):
- Dieu gi da tot?
- Dieu gi chua tot?
- Dieu gi can dung ngay?
- Action item tuan sau (owner + deadline)?
