## PHÁT HIỆN LỚN NHẤT — 9/9 hook đã chết im lặng

`~/.opencode/package.json` đặt `"type": "module"`, nên mọi file `.js` trong `scripts/` bị Node đọc như ESM. Hook viết bằng CommonJS chết ngay:

```
ReferenceError: require is not defined in ES module scope
```

| Tầng | Hook chết |
|---|---|
| PreToolUse | `block-no-verify`, `auto-tmux-dev`, `tmux-reminder`, `git-push-reminder`, `commit-quality`, `gateguard-fact-force` |
| PostToolUse | `command-log-audit`, `command-log-cost`, `pr-created`, `build-complete` |

Đã xác nhận chết **trước khi tôi sửa** (chạy bản `.bak` nguyên bản cũng lỗi ở dòng 4).

**Đây là lý do `--no-verify` và commit file deny-list chưa bao giờ bị chặn** dù có hook.

**Fix:** thêm `~/.opencode/scripts/package.json` với `{"type":"commonjs"}`. An toàn — đã quét `scripts/`, **không có file ESM nào** (không `import`/`export` ở 12 dòng đầu). Không đụng `~/.opencode/package.json` nên phần còn lại của config không bị ảnh hưởng. → 9/9 sống lại.

## 3 lỗi thiết kế của chính tôi, bị test che

1. **Preflight đọc `.git/COMMIT_EDITMSG`** — file đó chứa message của commit **trước**, không phải commit đang soạn. Commit P1 của tôi có nhắc `Claim-Deny-List:` nên check bị bỏ qua → **false negative**. Fix: `--commit-msg`, hook truyền message thật từ `-m`.
2. **Hook async tự đọc stdin** — dispatcher gọi `hook.run(raw)` **đồng bộ** và cần `module.exports.run`. Viết lại đúng khôn.
3. **`split-agents-md.mjs` mất 62 dòng nội dung sống** — cắt ngay sau tiêu đề `## Progress` nên xoá luôn 5 `OPEN P0` + 2 mục mốc. Bắt được nhờ `git diff --numstat` cho 579 delete trong khi archive chỉ 517. Khôi phục bằng `git checkout`, sửa mốc dừng.

Ngoài ra tôi mắc lại **"gate qua pipe"**: `$LASTEXITCODE` sau `node … | Select-Object` lấy exit của `Select-Object`, không phải của node — tưởng preflight trả 0 trong khi nó trả 1.
