# 11.01 — Quy Trình Phát Triển

> Cầu nối giữa `docs/AGENT_PROTOCOL.md` (multi-agent) với bộ hồ sơ này. Vòng đời
> một slice (code + docs cùng một PR):

## 1. Vòng đời slice

1. Nạp `project-lessons` theo tag → ghi `Lessons áp dụng` vào plan (planning gate).
2. Khai claim (`docs/CLAIMS.md`), commit riêng, branch `feat/<slice>-<agent>`
   — trước dòng đầu tiên, không commit thẳng `dev`.
3. Đọc phân hệ liên quan trong bộ này trước khi code (biết "đang ở đâu").
4. Code xong: chạy tools docs (`--write` nếu đổi số liệu, rồi `--check` exit 0).
5. Gate sau rebase → claim `done` → push (pre-push gate 22 xanh) → PR → merge →
   append ledger Entry → cleanup branch.

## 2. Definition of Done theo loại slice

| Loại | DoD kiểm thử | DoD tài liệu |
|---|---|---|
| BE | `manage.py check` + `makemigrations --check` + test app đó xanh (PG thật) | Endpoint/model đổi ⇒ regen catalog + `--check` |
| FE | `tsc` 0 + `eslint` 0 error + component test + `build` 0 | Route mới ⇒ vào `routeCatalog` (D-01) + contract test |
| Docs | `--check` exit 0 + self-test khi sửa tool | Số mới ⇒ khai `claims.json`; ảnh chụp ghi ngày |
| Infra/compose | `docker compose config` + deploy staging thử | Cập nhật `09.01` + runbook |

## 3. Quy ước cứng (từ bài học đã trả giá)

- EOL: file `.md`/mã mới thuần LF; kiểm `git diff --numstat` trước stage (L-T01).
- Không `npm install`/`pip install` khi chưa hỏi (node_modules dùng chung).
- Không `git checkout --` để hồi quy thử nghiệm (mất việc chưa commit — L-A01);
  copy ra ngoài trước.
- Không `--no-verify` để lách hook trừ khi ghi lý do vào commit body.
- Citation `file:line`: mở đúng file đọc đúng dòng, trích nguyên văn (L-T02).

## 4. Khi sửa code mà tài liệu liên quan đã lệch

Xử lý lệch **trước** (chạy `--check` đỏ từ đầu ⇒ sửa chồng lên là sai — xem
`00.03` §3.1).
