# 06.01 — Tổng Quan Mô Hình Dữ Liệu

> Quy mô: 116 model, 135 migration (máy đo — claims `C-002`, `C-003`, chi tiết
> từng field ở `06.02-danh-muc-model.md`). Data dictionary đầy đủ ở
> `D02` §4 (sinh bởi `gen_data_doc.py`).

## 1. Cụm dữ liệu (phân theo ranh giới trách nhiệm)

| Cụm | App | Dữ liệu giữ | Quy tắc tenant |
|---|---|---|---|
| Tiền | `user_workspace` | Portfolio, Transaction, LedgerEntry, định giá | Mọi bảng tiền có tenant FK; sổ cái append-only (mục 2) |
| Nền tảng truy cập | `identity_access`, `tenant_lifecycle` | User, CoreTenant, PAT, credential | Bảng này **chứa** tenant — là gốc của mọi FK tenant |
| Thị trường | `market_data`, `market_serving`, `data_ingest`, `signal_intelligence` | Giá, nến, tín hiệu, cache warmup | Dữ liệu dùng chung + nhật ký theo tenant — verdict từng model ở `06.02` cột tenant FK |
| AI | `advisory`, `ai_agents`, `ai_analytics` | Phiên, bản ghi, cấu hình, thống kê dùng | Theo user (BYOK), tenant kế thừa qua user — verdict F-ADVSR-02 ở dossier `advisory` |
| Thương mại | `commercial`, `advertising`, `support` | Đơn, chiến dịch, vé hỗ trợ | Theo tenant |
| Vận hành | `service_ops`, `ops_audit` | Job, audit log | Audit log fail-closed theo tenant (`qs.none()` khi thiếu scope) |

> Bảng trên là khung trách nhiệm. Verdict "model X thiếu tenant FK có phải lỗi
> không" nằm ở dossier từng app (`MODULES/`), không kết luận ở đây.

## 2. Ba bất biến đã verify (đọc code thật 2026-10-14)

1. **Sổ cái append-only.** `LedgerEntry` kế thừa `AppendOnlyMixin`
   (`user_workspace/models.py:1040`). Sửa quá khứ chỉ bằng entry đảo (`reversal_of`),
   và một dòng chỉ được đảo đúng một lần (`:1157-1161`
   `uniq_ledger_entry_single_reversal`).
2. **Idempotency theo tenant.** Unique `(tenant, external_id)` có điều kiện
   (`:1150-1154` `uniq_ledger_entry_tenant_external_id`) — rào chắn cho case
   backfill ghi trùng (xem migration `0022_backfill_transaction_to_ledger.py`
   + claim `ledger-sync-p0` trong `docs/CLAIMS.md`).
3. **Không có "ẩn danh mục".** `Portfolio` **không có** field `is_archived`
   (grep toàn file 0 kết quả); tenant FK NOT NULL (`:35-43`). Thông điệp 409 cũ
   khuyên "hãy ẩn danh mục" là sai — đã sửa thành `suggested_action: rename`.
