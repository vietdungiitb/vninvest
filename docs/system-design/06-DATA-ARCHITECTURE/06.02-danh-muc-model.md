> Sinh ngày 2026-10-15 bằng `docs/system-design/_meta/tools/gen-model-catalog.py` (Django runtime: `apps.get_models` + doc `migrations/`).
> Lệch với code ⇒ `--check` đỏ. Muốn sửa: đổi model/migration rồi chạy `--write`, không sửa tay file này.
