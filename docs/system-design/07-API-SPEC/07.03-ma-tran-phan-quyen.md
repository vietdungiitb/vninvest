## 2. Danh sách endpoint AllowAny (30 route — đã rà từng path)

| Nhóm | Path | Vì sao công khai |
|---|---|---|
| Auth | `/api/auth/*` + `/core/v1/auth/*` (login, register, token, refresh, verify-email, password-reset, resend) | Bắt buộc công khai (chưa có token) |

## 4. Quy tắc duy trì

- Ma trận §1 sinh lại từ `07.02` khi đổi phân quyền (không sửa tay con số).
- Thêm endpoint AllowAny mới ⇒ ghi lý do vào bảng §2 (công khai là quyết định
  bảo mật, phải có chữ ký reviewer).
- Thêm mã lỗi mới ⇒ thêm dòng vào §3 kèm `file:line`.
