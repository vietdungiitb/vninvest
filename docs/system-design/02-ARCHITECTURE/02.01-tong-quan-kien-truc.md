# 02.01 — Tổng Quan Kiến Trúc

> Ngày rà: 2026-10-14. Container đo từ `docker-compose.prod.yml` + overlay;
> FE đo từ registry/adapter; module map từ 15 app (claim `C-001`).

## 1. Containers (triển khai staging/prod)

| Container | Vai trò | Nguồn |
|---|---|---|
| `nginx-proxy` + `acme-companion` | Reverse proxy đa domain + Let's Encrypt (label-based) | `docker-compose.nginx-proxy.yml` |
| `frontend` (nginx) | Phục vụ SPA đã build (lazy chunk theo route) | `packages/web` |
| `core-api` | Django API (`core/v1` + legacy `/api/v1`) | `packages/core/backend` |
| `core-worker` + 2 worker realtime | Celery: ingest/backfill + prefetch/stream | `CELERY_BEAT_SCHEDULE` (42 lịch) |
| `core-beat` | Lập lịch Celery beat | — |
| `core-db` (Postgres) + `pgbouncer` | DB chính (bắt buộc PG) + pool | — |
| `core-redis` + `queue-drain-monitor` + `redis-exporter` | Queue/cache + giám sát + metrics | — |
| `prometheus` + `grafana` | Quan trắc | — |

Sơ đồ đầy đủ ở `03.01` (C4-02).

## 2. Frontend shell (app shell + registry + adapter)

- Entry `packages/web/src/main.tsx`: routeId theo `routeCatalog` (chuẩn D-01),
  resolver map id catalog → component registry.
- `packages/web/src/pages/pageRegistry.js`: code-split theo route bằng lazy
  `import()` ở registry (số chunk đo từ bundle deploy, không viết tay vào đây).
- Tầng gọi BE duy nhất: `packages/web/src/adapters/core/` (không gọi fetch
  trực tiếp từ component).
- Widget biểu đồ qua npm `vninvestcharts-widget` (async chunk, không bundle chung).

## 3. Backend (15 app → 7 cụm, chi tiết ở `04.01`)

Tiền (`user_workspace`) · Nền tảng (`identity_access`, `tenant_lifecycle`,
`vninvest_core`) · Thị trường (`market_data`, `market_serving`, `data_ingest`,
`signal_intelligence`) · AI (`advisory`, `ai_agents`, `ai_analytics`) ·
Thương mại (`commercial`, `advertising`, `support`) · Vận hành (`service_ops`,
`ops_audit`).

## 4. Quyết định đóng gói (ghi nhận; ADR hồi tố ở slice ADR)

- FE: lazy theo route, chunk riêng cho trang nặng (portfolio/broker).
- BE: tách app theo miền + worker theo hàng đợi (ingest/realtime/offhours).
- Mọi API core bọc envelope `{data, meta}` (gate 9/9 app).
- Secret môi giới qua `SecretStore` (Fernet), không đọc trực tiếp env trong view.

## 5. Việc còn lại của phân hệ

C4 component cho 2 app phức tạp nhất (`user_workspace`, `identity_access`) +
sequence đặt lệnh chi tiết — viết khi dossier MODULES của chúng lên ✅ sâu.
