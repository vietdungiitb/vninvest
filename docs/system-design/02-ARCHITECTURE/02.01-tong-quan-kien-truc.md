# 02.01 — Tổng Quan Kiến Trúc

> ⏳ STUB Phase 1 — khung và nguồn sự thật. Nội dung chi tiết viết ở slice kiến
> trúc (sau khi xong 04/05/06/07).

## 1. Mục đích của phân hệ này

Mô tả các khối hệ thống, ranh giới, luồng gọi chính: app shell React → adapter
(`packages/web/src/adapters/core/`) → API Django (`core/v1`) → worker Celery →
PostgreSQL/Redis → nguồn thị trường/môi giới. Kèm C4 context/container, bản đồ
module, quyết định đóng gói.

## 2. Nguồn sự thật hiện có (đọc trước khi viết)

- `docs/architecture/D02_DATA_AND_ARCHITECTURE.md` — C4 container/component, DFD,
  cache/transaction/ACID (AS-IS, verify 2026-10-03).
- `docs/architecture/D01_AS_IS_OVERVIEW_AND_AUDIT.md` §2 — phân rã chức năng (FBD), RBAC.
- `packages/web/src/app/routeCatalog.js` — danh sách route thật (chuẩn D-01).
- `packages/web/src/pages/pageRegistry.js` — ánh xạ route → component render.
- `scripts/check-shell.mjs` — gate kiến trúc shell (assert entry `portfolios`).

## 3. Việc của slice kiến trúc

1. Vẽ C4 context + container từ code hiện tại (không copy ảnh cũ mà không kiểm).
2. Bản đồ module: 15 app → capability → route nhóm (đếm từ registry, không đếm
   theo tên file — L-G07).
3. Quyết định đóng gói FE (lazy chunk) và BE (app/api/worker) + ADR tương ứng.
4. Mọi sơ đồ Mermaid phải render được (lưu ý cảnh báo render C4 ở
   `architecture/README.md` §0.4 cuối).
