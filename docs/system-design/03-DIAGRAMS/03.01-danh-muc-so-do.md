# 03.01 — Danh Mục Sơ Đồ

> ⏳ STUB Phase 1. Mọi sơ đồ trong bộ này tuân thủ: Mermaid render được, mỗi sơ đồ
> có mục "Nguồn" liệt kê file code sinh ra nó, và ngày kiểm chứng.

## 1. Quy ước

- C4 (context/container/component), FBD (phân rã chức năng), DFD (luồng dữ liệu),
  ERD (quan hệ thực thể), sequence (luồng công việc chính).
- Sơ đồ vẽ từ code đang chạy (AS-IS). Sơ đồ định hướng ghi rõ TO-BE + liên kết ADR.
- Sơ đồ lỗi thời không xóa ngầm: đánh dấu `LỖI THỜI (ngày)` + liên kết thay thế.

## 2. Danh mục (khởi tạo ở slice sơ đồ)

| Mã | Sơ đồ | Nguồn code | Trạng thái |
|---|---|---|---|
| C4-01 | Context: vninvest và hệ ngoài | `D01` §2 + `compose` | ⏳ Chưa vẽ lại từ code |
| C4-02 | Container: web/api/worker/db/queue | `docker-compose*.yml` | ⏳ Chưa vẽ lại từ code |
| FBD-01 | Phân rã chức năng 15 app | `D01` §2.1 + `MODULES/` | ⏳ Chưa vẽ lại từ code |
| DFD-01 | Luồng dữ liệu đặt lệnh → sổ cái | `D02` + dossier `user_workspace` (viết ở slice MODULES) | ⏳ Chưa vẽ lại từ code |
| ERD-01 | Quan hệ thực thể chính | `D02` §4 (data dictionary 107 model) | ⏳ Trỏ D02 |

Nguồn hiện có: `D01` (FBD, RBAC), `D02` (DFD, ERD).
