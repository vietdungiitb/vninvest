# 01.01 — Tóm Tắt Điều Hành

> Hệ thống là gì, quy mô bao nhiêu, tình trạng ra sao — đọc trong 2 phút. Mọi con
> số cố định dưới đây đều có mục trong `_meta/claims.json`; số biến động nhanh
> xem bảng VOLATILE ở `_meta/freshness-report.md`.

## 1. Hệ thống là gì

**vninvest** là nền tảng đầu tư chứng khoán Việt Nam: quản lý danh mục, dữ liệu
thị trường, trung tâm tín hiệu (SOC), khuyến nghị AI, đặt lệnh qua môi giới DNSE,
phục vụ đa tenant. Frontend React SPA + backend Django API + worker bất đồng bộ.

## 2. Quy mô (máy đo 2026-10-14)

| Mảng | Số liệu |
|---|---|
| Backend | 15 Django app nghiệp vụ · 107 model · 117 migration |
| API runtime | 1473 route (trong đó 615 `core/v1`) — biến động nhanh, xem freshness-report |
| Vận hành | 10 compose stack · 42 lịch Celery beat |
| Frontend | React SPA, 563 file tracked trong `packages/web/src` — biến động nhanh |
| Tài liệu | 1755 file `.md` toàn `docs/` — biến động nhanh |

Định nghĩa "app nghiệp vụ": thư mục có `models.py`/`apps.py`/`migrations/0*.py`
dưới `packages/core/backend/src`, trừ `vninvest_core` (project package).
Quy mô tài liệu trong bộ này: xem bảng §4 trang vào.
