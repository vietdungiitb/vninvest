# 00.01 — Quản Trị Tài Liệu

> Ai được sửa cái gì, theo quy trình nào, ai duyệt. Đọc trước khi thêm/sửa bất kỳ
> file nào trong bộ hồ sơ này.

---

## 1. Chủ sở hữu và vai trò

| Vai trò | Người | Trách nhiệm |
|---|---|---|
| Chủ sở hữu bộ hồ sơ | PM/Tech Lead | Quyết định cấu trúc, duyệt slice nội dung, chốt mâu thuẫn |
| Người viết slice | Agent/dev có claim | Viết đúng phạm vi claim, kèm `file:line`, chạy tools trước PR |
| Máy canh (gate) | `check-system-design.mjs --check` | Chặn drift số liệu, link chết, citation chết, trùng chủ đề |
| Di sản `architecture/` + `saas_design_pack/` | Session sở hữu riêng | Bộ này chỉ trỏ tới, không sửa (xem `00.04-ban-do-chu-de.md`) |

## 2. Quy trình làm việc với bộ hồ sơ (bắt buộc)

Mọi thay đổi tuân `docs/AGENT_PROTOCOL.md` như code:

1. **Khai claim** vào cuối `docs/CLAIMS.md`, commit riêng, trước dòng đầu tiên.
   Phạm vi file: `docs/system-design/**` là file mới tự do (§2 protocol).
2. Làm trên branch `feat/<slice>-<agent>`, **không commit thẳng `dev`**.
3. Trước khi PR: chạy `node docs/system-design/_meta/tools/check-system-design.mjs`
   rồi `--check` — phải exit 0 (xem [00.03](00.03-quy-trinh-dong-bo.md) §4).
4. Mọi khẳng định về code kèm `file:line` đọc từ file thật; chưa kiểm chứng thì
   ghi ❓ CHƯA XÁC MINH, không đoán.
5. Mọi con số máy đo được phải có mục trong `_meta/claims.json` (không viết số
   "trôi nổi" trong tài liệu viết tay).
6. Sau merge: append 1 Entry vào `docs/CODE_CHANGE_AUDIT_LEDGER.md` (đã được gỡ
   khỏi deny-list từ 2026-10-03).

**Cấm:**

- Sửa file shared (`AGENTS.md`, `packages/web/package.json`, `docker-compose*.yml`,
  `.env*`, … — xem `AGENT_PROTOCOL.md` §2). Cần đổi gate/package thì ghi vào claim,
  báo coordinator.
- Sửa/xóa dòng cũ trong file append-only (`docs/CLAIMS.md`, ledger). Chỉ append.
- Báo "PASS" cho gate chưa chạy — ghi "CHƯA CHẠY" (L-G02).

## 3. Chu kỳ rà soát

| Sự kiện | Việc |
|---|---|
| Mỗi PR đụng `docs/system-design/**` | Gate `--check` chạy (pre-push + review tay) |
| Quá 30 ngày không PR nào đụng bộ hồ sơ | Chủ sở hữu chạy tools + rà `_meta/freshness-report.md` |
| Mỗi slice Phase 2+ merge | Cập nhật bảng trạng thái ở `README.md` §4 |

## 4. Thêm/xóa phân hệ

Cấu trúc 13 phân hệ theo khung chung 3 repo anh em (`vninvestcharts-widget`,
`vnsaas`, `ERP-Edusuccess`). Thêm phân hệ mới (vd `12-OPERATIONS/`) cần quyết định
của chủ sở hữu + ghi ADR. Không tự ý đổi tên thư mục đã có trích dẫn trỏ tới.
