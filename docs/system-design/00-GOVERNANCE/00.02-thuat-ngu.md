# 00.02 — Thuật Ngữ Thống Nhất

> Một khái niệm, một định nghĩa, một nơi. Viết tắt/label tiếng Việt trong UI theo
> bảng này. Nguồn gốc đầy đủ: `docs/architecture/D01_AS_IS_OVERVIEW_AND_AUDIT.md`
> §1.3 (bảng thuật ngữ và thực thể miền).

## 1. Quy ước

- Tên file tài liệu: tiếng Việt không dấu, dạng `NN.NN-ten-chu-de.md`.
- Nội dung: tiếng Việt có dấu đầy đủ. Thuật ngữ kỹ thuật giữ nguyên tiếng Anh
  khi không có từ Việt tương đương (`tenant`, `migration`, `beat`).
- UI labels: tiếng Việt đầy đủ dấu, theo bảng thuật ngữ thống nhất của dự án.
- Thuật ngữ mới chỉ được thêm kèm cột Nguồn (`file:line` đã đọc thật).

## 2. Bảng hạt giống (mở rộng dần theo slice)

| Thuật ngữ | Nghĩa | Nguồn |
|---|---|---|
| Tenant | Đơn vị thuê bao — ranh giới cô lập dữ liệu số 1 | `D01` §1.3 |
| PAT | Token truy cập cá nhân, quay vòng khi reset/change password | `D01` §1.3 |
| Envelope | Khung đáp `{data, meta}` của mọi API core | `D03` + `vninvest_core/api_envelope.py` |
| SOC | Trung tâm điều hành tín hiệu (Signal Operations Center) | `D01` §2 |
| DNSE | Công ty chứng khoán kết nối đặt lệnh thật | `D01` §1.3 |
| Ledger | Sổ cái append-only, lưu ≥ 7 năm (D-17) | `D01` §1.3 |
| Claim (docs) | Dòng khai báo sở hữu file trong `docs/CLAIMS.md` | `AGENT_PROTOCOL.md` §3 |
| Slice | Đơn vị công việc có AC + gate, merge qua PR | `AGENT_PROTOCOL.md` §10 |
| Gate | Kiểm tra chặn (fail-closed), exit ≠ 0 là dừng | `scripts/pre-push-gate.mjs` |
| Beat | Lịch định kỳ Celery (`CELERY_BEAT_SCHEDULE`) | `vninvest_core/settings.py` |

> Bảng trên là hạt giống Phase 1. Mỗi slice viết về app nào thì bổ sung thuật ngữ
> miền của app đó vào đây (kèm nguồn), không định nghĩa rải rác trong các dossier.
