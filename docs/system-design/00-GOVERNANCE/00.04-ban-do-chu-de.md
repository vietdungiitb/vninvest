## 4. Quy tắc AS-IS vs TO-BE (nhắc lại từ `architecture/README.md` §0)

| Cần biết | Đọc |
|---|---|
| Hệ thống **đang** chạy thế nào, code ở đâu | `docs/architecture/` (AS-IS) |
| Hệ thống **sẽ** được xây thế nào | `docs/saas_design_pack/` (TO-BE) |
| Đọc cái gì trước, cái gì còn đúng | Bộ này (`system-design/`) |
