## 1. Bản đồ triển khai

- **Staging (mặc định(editorial, mọi chạy thử):** VPS `14.225.255.47`,
  `https://docker.edusuccess.vn`, repo `/opt/vninvest` (branch `dev`),
  deploy bằng `bash scripts/deploy-staging.sh` — xem `docs/STAGING_VPS_RUNBOOK.md`.
- **Stack:** 10 compose stack (máy đo — claim `C-004`), gồm app + db + redis +
  pgbouncer + proxy + monitor.
- **Giới hạn RAM staging:** `CORE_API_MEM_LIMIT=2g` trở lên (full BE suite cần
  ≥ 2 GiB; exit 137 = OOM — xem `compose.staging.env.example`).

2. Runbook sự cố theo từng tầng (proxy → app → worker → db).
3. Lịch backup/restore và quy trình rotate secret (P0-SEC-01 đang mở — repo PUBLIC).
