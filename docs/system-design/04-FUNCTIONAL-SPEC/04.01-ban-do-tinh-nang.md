# 04.01 — Bản Đồ Tính Năng (Phân Rã Chức Năng)

> ⏳ STUB Phase 1. Phân hệ này trả lời: hệ thống làm được những gì, tính năng nào
> thuộc app nào, tính năng nào đã có test khóa hành vi.

## 1. Khung phân rã (khởi tạo ở slice chức năng)

```
vninvest
├── Danh mục (user_workspace) — CRUD, KPI, holdings, định giá NAV
├── Thị trường (market_data, market_serving) — ingest, phân phối, warmup
├── Tín hiệu (signal_intelligence, SOC) — cảnh báo, trung tâm điều hành
├── Khuyến nghị AI (advisory, ai_agents, ai_analytics) — pipeline 3 sub-agent + synthesis
├── Môi giới (commercial + DNSE) — đặt lệnh fail-closed, idempotency
├── Nền tảng (identity_access, tenant_lifecycle) — auth, PAT, đa tenant
├── Vận hành (service_ops, ops_audit, support, advertising) — control plane, audit, hỗ trợ
```

> Cây trên là khung định hướng từ tên app — ❓ CHƯA XÁC MINH đầy đủ. Slice chức
> năng phải trace mỗi nhánh tới route + test thật rồi mới bỏ nhãn này.

## 3. Quy tắc

Mỗi tính năng lá ghi: route/API → app BE → test khóa (file test) → trạng thái.
Tính năng không có test khóa thì ghi rõ "không có test", không ghi "đã ổn".
