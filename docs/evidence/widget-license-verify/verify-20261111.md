## 2. Root cause (code đã đọc, không đoán)

`packages/web/node_modules/@vninvestcharts/engine-core/dist/index.js`
(vùng verify, quanh `activePublicKeys.filter`):

```js
const wantedKid = parsed.payload.k;
const candidates = wantedKid !== void 0
  ? activePublicKeys.filter((jwk) => jwk.kid === wantedKid)
  : activePublicKeys;
if (wantedKid !== void 0 && candidates.length === 0) return null;
```

- Key có `k="primary"`; `activePublicKeys` stock = 3 kid nhúng
  (`prod-2026-10-17`, `e2e-2026-10-31`, `prod-2026-11-09` — grep toàn bundle:
  chuỗi `"primary"` 0 hit).
- ⇒ `candidates` rỗng ⇒ `return null` trước cả khi thử chữ ký.
- Rào product (W1) đã xong (`LICENSE_PRODUCTS` chứa `vninvestcharts_widget`);
  rào kid vẫn nguyên — đúng blocker F-VFY-02 của audit trước.
