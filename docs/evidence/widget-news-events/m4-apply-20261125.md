## Lỗi trong lúc chạy (không làm hỏng dữ liệu)
- Lần 1: `Unknown command price_migration_persist` — code chưa deploy vào image staging ⇒ copy file.
- Lần 2: `Cannot resolve keyword 'price_source'` — model class trong container cũ ⇒ copy `models.py`.
- Lần 3: `NameError: opts is not defined` trong `_write_inserts` (bug thật trong code M4) ⇒ sửa `if opts['apply']` → `if True`.
- Lần 4: `could not resize shared memory segment "/PostgreSQL..." No space left on device` ở bước **VACUUM ANALYZE sau khi ghi xong** — pgbouncer `/dev/shm` chỉ 64 MB. **Dữ liệu đã commit đúng** (xem bảng trên); đã bỏ VACUUM khỏi command, để chạy riêng nếu cần.
