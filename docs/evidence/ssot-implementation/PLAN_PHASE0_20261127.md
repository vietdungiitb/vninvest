## 1. Định nghĩa "mã active" (objection 1)
```
active = {s | StockProfile.objects.filter(status='active').values_list('symbol',flat=True)}
with2026 = {s | DailyPrice.objects.filter(date__gte='2026-01-01').values_list('symbol',flat=True).distinct()}
denominator = active ∩ with2026
covered = {s in denominator | tồn tại DailyPrice(s, price_source in ('vnbroker_legacy','cafef','vnbroker_fallback'))}
STOP nếu |covered| / |denominator| < 0.95
```
