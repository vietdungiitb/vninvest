## 4. Bẫy quy trình đã gặp thật trong các phiên gần đây

Phần này để phiên sau không mất thời gian vào cùng lỗi.

| Bẫy | Hệ quả | Cách tránh |
|---|---|---|
| Chạy `python manage.py test` bằng `python` trên PATH | Đó là Python hệ thống (`WindowsApps\python.exe`), không phải venv ⇒ `ModuleNotFoundError` giả, tưởng code hỏng | Luôn dùng `& .\.venv\Scripts\python.exe manage.py test ...` |
| `pip install --no-deps` | Thiếu dependency (`websockets`) ⇒ `import vnbroker` fail | Chỉ dùng `--no-deps` khi biết chắc; dry-run trước vì venv dùng chung qua junction cho nhiều worktree |
| Đặt tên test `*.contract.test.js` | `vitest` chỉ include `src/**/*.component.test.*` ⇒ **không chạy**, trả `No test files found` exit 1 — trông như pass | Kiểm `include` trong `vitest.config` trước khi đặt tên |
| Comment chứa từ cấm (`process.env.REACT_APP_`) | `not.toMatch()` khớp cả comment giải thích lịch sử ⇒ assert đỏ oan | Strip comment trước khi assert |
| `git mv` với file untracked | Fail, rồi `Remove-Item -Recurse` **xoá mất** file | Dùng `Move-Item` cho file untracked |
| PowerShell here-string `@"…"@` chứa `${VAR}` | Bị interpolate ⇒ commit message hỏng | Viết message ra file, dùng `git commit -F` |
| `git stash push -- <path>` chạy sai cwd | Chạy nhầm trong main tree, suýt đụng việc agent khác | Luôn truyền `workdir`, kiểm tra lại bằng `git status` |
| Sửa file shared (`docker-compose*.yml`, `.env*`) | Hook chặn (đúng thiết kế) | Chỉ coordinator sửa; nếu dùng `--no-verify` thì **ghi lý do vào commit body** |
| Commit claim-release thẳng vào `dev` | Vi phạm protocol §2 | Tạo branch + PR, kể cả thay đổi 1 dòng doc |
| Sau `gh pr merge --delete-branch`, **local branch bị chuyển về `dev`** | `git push` kế tiếp đẩy thẳng lên `dev`, bỏ qua PR. **Đã xảy ra 2 lần** | Sau khi merge: kiểm `git rev-parse --abbrev-ref HEAD` **trước khi** commit/push lần sau. Nếu đã ở `dev`, tạo branch trước: `git checkout -b <ten>` |
| `Add-Content` khi file không có newline cuối | Row mới **dính vào dòng trước** thành 1 dòng hỏng | Kiểm `Split('\|')` sau khi append vào bảng |
| Tự đặt số migration | `Conflicting migrations` — chặn deploy | Đọc head thật hoặc để `makemigrations` sinh |
| Lập luận suông về code rồi tin vào | Đã 2 lần: (1) tưởng extractor trả sai vì khoá 5 phần — hoá ra `parts[-2]` rơi đúng; (2) tưởng `Test-Path` bằng glob hoạt động | Chạy thử rồi mới kết luận. Đặc biệt khi viết test |
