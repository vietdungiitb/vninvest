# Roadmap Phat Trien Ke Thua (2026Q2-2026Q4)

## Muc tieu tong the
- Ke thua he thong da co (React + Django + Pandas), khong pha vo API dang chay.
- Dong bo domain voi tai lieu nghiep vu Portfolio Tracker + Pro Watch + Robo-Advisor.
- Dua vao van hanh duoc realtime pipeline (Redis + Celery) va module tu van giao dich.

## Nguyen tac trien khai
- On dinh truoc, mo rong sau: uu tien do chinh xac du lieu va tinh toan tai chinh.
- API co version khi thay doi lon: giu route cu, them route moi cho chuc nang nang cao.
- Tieu chuan ho logging, retry, timeout truoc khi scale worker.
- Moi sprint co KPI ro rang va Definition of Done.

## Muc luc sprint moi

### Sprint 7 - Domain Alignment va API Contract (2 tuan)
Muc tieu:
- Chot schema thuc te theo tai lieu nghiep vu, giam no ky thuat do model/route lech.

Deliverables:
- Chot domain model: UserConfig, SubAccount, Transaction, AccountSnapshot, Watchlist, ScreenerRule, StockProfile, DailyPrice.
- API contract v1.1 cho Portfolio + Stock Management.
- Ke hoach migration an toan (SQLite -> PostgreSQL neu can) + rollback.
- Danh sach endpoint can deprecate va endpoint thay the.

KPI:
- 0 blocking bug do schema mismatch tren luong giao dich.
- 100% endpoint co tai lieu request/response va ma loi.

### Sprint 8 - Portfolio Engine v2 va Margin Logic (2 tuan)
Muc tieu:
- Dam bao do dung tai chinh cho holdings, cost basis, NAV, margin sub-account type 6.

Deliverables:
- Chuan hoa weighted average cost va edge case (ban vuot, co tuc, phi).
- Margin ratio, buying power, canh bao nguong rui ro co ban.
- Snapshot NAV luc 15:30 theo lich.
- Unit test cho cong thuc cot loi.

KPI:
- Sai lech NAV < 0.1% so voi bo du lieu kiem chung.
- Test pass >= 70% cho analytics core.

### Sprint 9 - Performance va Benchmark (2 tuan)
Muc tieu:
- Hoan thien bao cao hieu suat dung cho nha dau tu.

Deliverables:
- Tinh TWR theo ngay/tuan/thang.
- Benchmark VN-Index va equity curve.
- API report + UI chart hieu suat.
- Export CSV (ban dau).

KPI:
- p95 API report < 300ms (du lieu da co trong DB).

### Sprint 10 - Realtime Event-Driven Foundation (2 tuan)
Muc tieu:
- Chuyen tu polling API sang WebSocket event-driven de tranh request storm khi nhieu user online.

Deliverables:
- Django Channels + ASGI stack cho WebSocket gateway.
- Redis Pub/Sub channels (vd: channel_{symbol}_ticker) cho su kien gia va whale alert.
- Celery collector polling 5 giay + Pandas compute (VWAP/Whale) + publish su kien.
- Proxy rotation cho collector worker + retry/backoff/circuit breaker.
- Fallback HTTP polling khi WebSocket bi gian doan.

KPI:
- p95 push latency (publish -> client receive) < 1.5s.
- p95 websocket fanout < 200ms tren moi node.
- Ty le worker task thanh cong > 99% trong gio giao dich.

### Sprint 11 - Pro Watchlist va Alerting (2 tuan)
Muc tieu:
- Tang gia tri su dung hang ngay cho user theo doi thi truong.

Deliverables:
- Alert center realtime (whale 500tr/1 ty, break VWAP, volume spike).
- Push thong bao qua WebSocket va Telegram Bot.
- Rule canh bao theo user config (nguong, nhom ma, tan suat).
- Dashboard health cho websocket channel va worker queue.

KPI:
- 0 crash frontend khi websocket timeout/disconnect.
- Alert push < 3s ke tu luc phat hien whale.

### Sprint 12 - Custom Screener JSON Engine (2 tuan)
Muc tieu:
- Cho phep user tu dinh nghia bo loc ky thuat bang JSON.

Deliverables:
- DSL JSON rule (RSI, MA, Volume, Price).
- Rule parser + evaluator tren Pandas (vectorized operations).
- CRUD ScreenerRule + run scan API.
- Luu lich su ket qua scan.
- Chuan bi input cho backtest 3-5 nam tu DailyPrice time-series.

KPI:
- 95% rule hop le duoc parse va chay khong loi.

### Sprint 13 - Robo-Advisor Rule-based (2 tuan)
Muc tieu:
- Xuat goi y giao dich co giai thich va quan tri rui ro.

Deliverables:
- Scoring engine (trend, momentum, volume, risk).
- De xuat Entry/Stop-loss/Take-profit theo ATR.
- Audit log ly do khuyen nghi.
- Backtest service: parse rule JSON -> simulate trade -> metric report.
- Metric toi thieu: Win Rate, Profit Factor, Max Drawdown.

Cong thuc metric can chuan hoa:
- Win Rate = (So lenh co lai / Tong so lenh da dong) * 100
- Profit Factor = Tong loi nhuan lenh thang / Tong thua lo lenh thua

KPI:
- Moi khuyen nghi deu co explanation + confidence score.
- Backtest 3 nam du lieu tra ket qua < 30s cho rule pho bien.

### Sprint 14 - Production Hardening (2 tuan)
Muc tieu:
- San sang release production.

Deliverables:
- CI/CD + migration checklist + rollback playbook.
- Observability: log cau truc, metric, alert.
- Bao mat: rate limit, permission matrix, token policy.
- Smoke test E2E truoc release.
- Mission Control admin nang cap: versioned config, draft/approval, audit log, propagation ACK.

KPI:
- Release candidate dat tieu chi runbook va monitoring.

### Sprint 15 - Whale Analytics Deep Dive (2 tuan)
Muc tieu:
- Nang cap module Whale Alerts tu viec dem so lan thanh phan tich dong tien sau hon.
- Dat nen tang cho AI Advisory chinh xac va co gia tri hanh dong hon.

Deliverables:
1. **Volume Weighting + Whale Avg Price**
   - Aggregate feed endpoint tra them `total_volume` per symbol.
   - `TrackedSymbolCard` dung color encoding theo tong gia tri (ty VND).
   - Whale Avg Price = totalValue / totalVolume hien thi trong card.

2. **Severity Tag he thong (Urgent/Warning/Info)**
   - `WhaleAdvisory` model them field `severity` (urgent/warning/info).
   - OpenClaw task set severity theo matched_value / threshold ratio.
   - `AdvisoryCell` hien thi tag mau.

3. **Reversal Alert Detection**
   - Celery task `detect_whale_reversal` chay sau batch ingest.
   - Phat hien pattern: ≥3 BUY trong 15p → SELL vot nguong → tao advisory type REVERSAL.
   - FE hien thi badge "⚠ Dao chieu".

4. **Timeframe Filter**
   - Aggregate feed API nhan param `?window=5m|15m|1h|session`.
   - `WhaleAlertsHub` co dropdown timeframe, tu dong refetch.

5. **Watchlist Sync Filter cho Advisory**
   - `getWhaleAdvisories` ho tro `?watchlist_only=true`.
   - Toggle trong `WhaleAdvisory.jsx`.

KPI:
- Volume Weighting dung cho >= 80% truong hop (fallback graceful khi khong co volume).
- Reversal detection false positive rate < 20% tren tap du lieu kiem thu.
- Timeframe filter p95 response < 500ms.
- 0 regression tren Whale Alerts hub hien tai.

Su phu thuoc:
- Can kiem tra `IntradayTick` model co field `volume` kha dung.
- Reversal logic can calibrate nguong theo dac tinh thi truong VN (khong ap dung thang tu cac thi truong khac).

### Sprint 16 - Whale History & Trading Journal (2 tuan)
Muc tieu:
- Bo sung lich su dong tien va so sach dau tu tu dong de nha dau tu danh gia hieu qua theo thoi gian.

Deliverables:
1. **Whale History Chart**
   - Endpoint `/api/portfolio/whale-history/?symbol=XXX&days=30`.
   - Component `WhaleHistoryChart` trong `WhaleAlertsDashboard`.
   - Bieu do cot: gom rong vs ban rong theo ngay.

2. **Trading Journal tu dong**
   - Model `AdvisoryOutcome`: price_at_signal, price_t1/t3/t5, outcome.
   - Celery beat task cap nhat outcome sau T+1/T+3/T+5 ngay giao dich.
   - API win rate per symbol.
   - FE: badge win rate trong `AdvisoryCell` (neu >= 5 lan du lieu).

KPI:
- Whale History hien thi chinh xac 30 ngay gan nhat.
- Advisory Outcome duoc cap nhat dung han cho >= 95% advisory trong gio giao dich.

Su phu thuoc:
- `DailyPrice` model da co — dung lam nguon gia dong cua.
- Can retention policy ro rang cho `IntradayTick` de Whale History query hieu qua.
